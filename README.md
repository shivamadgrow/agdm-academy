# AGDM Academy Website (PHP)

Responsive multi-page PHP website for AGDM Academy.

## Pages

- Home (`index.php`)
- About (`about.php`)
- Courses (`courses.php`)
- Services (`services.php`)
- Contact (`contact.php`)
- MIDM Course (`midm.php`)
- PIDM Course (`pidm.php`)

## Run locally

1. Open terminal in project folder.
2. Run:
  `php -S localhost:8000`
3. Open:
  `http://localhost:8000`

## Deploy on domain

Upload all files to your hosting public directory (`public_html`) for `agdmacademy.com`.
